## Outcome

Rows in a list line up, tables sort the way a person counts, and the screen that reports an assignment is not two-thirds empty white.

## Why now

The metadata block in the Markets list starts at a different horizontal position on every row, because the same markup is copied into four views with no shared grid.
The payoff screen stretches two empty columns to the height of a third, so the organizer scrolls roughly 1,300px of blank to reach the bottom.

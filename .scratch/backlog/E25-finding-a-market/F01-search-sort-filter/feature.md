## Outcome

The Markets page has a search box, an Organization filter, a Phase filter and a sort, all acting together on the list as the organizer changes them, and all held in the page's address.

## Why now

See the epic.
The list endpoint already returns every market the organizer can reach in one response, so this is a browser-side view over that list and needs no server change.

## What to build

The existing anonymiser for Google Form exports (in the back end's test fixtures) is extended so that it turns any of the five real exports into a committable copy, and the five copies are committed beside the one fixture that exists today.

It keeps what the proposal and the import read, and nothing that identifies anyone, by the privacy rule of [01](../../../wayfinding/the-form-started-from-a-csv/issues/01-what-hosted-jev-may-be-sent.md): the header row verbatim, and any value, or option inside a multi-select answer, that at least 3 distinct applicants share; everything else becomes an invented value of the same shape.
Blanks, row count and order, `TEST` rows, duplicate email columns and trailing empty columns stay as they are; timestamps move by one fixed offset.

`human-only`: the real exports live only on the maintainer's machine (git-ignored under `.scratch/examples/`), so generating the files needs them; an agent can write and test the script against a synthetic export, and the maintainer runs it on the five.

## Acceptance criteria

- [x] One anonymiser, extended rather than duplicated, and deterministic: running it twice on the same export produces byte-identical output.
- [x] What it keeps is decided by the distinct-applicant count, not by a list of header words.
- [x] It refuses to write anything if a source value of 4 or more characters that fewer than 3 applicants share appears anywhere in its output, and says which column.

## What to build

Any address can request a code and sign in while applications are open, keeping the uniform, non-enumerating responses; signing in with no application opens the empty form.

Closes bugs 6 in `docs/MVP_BUGS.md`; each one's reproduction there is the starting E2E.

## Acceptance criteria

- [ ] A brand-new address requests a code, signs in, submits and sees Submitted on Your Application.

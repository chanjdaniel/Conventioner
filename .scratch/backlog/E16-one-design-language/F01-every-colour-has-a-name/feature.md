## Outcome

Every colour the product paints comes from `base.css`, no reference resolves to nothing, and the checks that keep both true run in CI.

## Why now

This feature exists in one piece rather than nine because the nine reds, the two blues, the two undefined tokens and the two failing verdict buttons are all one edit to the palette. Fixed file by file they would be nine chances to pick a tenth red.

It goes first because it is pure addition - no layout changes, nothing to co-ordinate with the sizing decision - and because it closes the invisible **Archive Market** button, which sits in front of organizers now.

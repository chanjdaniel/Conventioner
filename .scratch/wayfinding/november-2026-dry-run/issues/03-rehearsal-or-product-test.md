# 03: Rehearsal or product test?

Type: grilling
Status: resolved
Blocked by: -

## Question

Is this run a **rehearsal** of the real November market, whose plan and verdicts must be the organizer's real ones so that its assignment could actually be used (or compared with the one made by hand), or a **product test** that uses the real file to find what breaks, where the plan can be approximated?

Everything after this depends on it: whether the real table counts are needed before the run can start ([04](04-the-real-plan.md)), whether the sheet's verdicts must be replayed ([05](05-whose-verdicts.md)), and what counts as a pass ([07](07-what-counts-as-a-pass.md)).

**Recommendation:** a rehearsal.
It costs only the plan facts in 04, and it is the only version whose result someone can look at and say "that is right" or "that is wrong": a product test with an invented plan can show the journey completes, which the 2026-10-03 re-walk already showed.

## Answer

Decided with the user on 2026-10-09: **a rehearsal.**
The run uses the market's real plan ([04](04-the-real-plan.md)) and the organizer's real verdicts ([05](05-whose-verdicts.md)), so its assignment can be judged right or wrong against what the organizer knows, and could be used for the real market.
Settled in the same round, for [06](06-path-and-how-far.md) and [07](07-what-counts-as-a-pass.md): intake is P2 (start the market from this file, then import it), the identical file is imported a second time to prove a re-import changes nothing, and bugs are fixed as found, each reproduced first in a failing spec.

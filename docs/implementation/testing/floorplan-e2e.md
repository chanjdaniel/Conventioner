# The layout's E2E

**Every gesture is a person's, and what it did is read from the screen and the server.**
A spec drags a table with `page.mouse`, presses keys on the focused map, and reads where the table went from its accessible name, the live region and the layout the server stored, never from the page's state through `page.evaluate`; so a bug in dragging, in a box select or in a key fails a spec, which the floorplan beta's specs, setting its store directly, could not promise.
**Deterministic, with no AI to mock.**
A location's layout calls no model ([its module](../modules/floorplan-placement.md)), so the specs run the real flow in CI with no API keys and no stubbing.
The glossary concept: [Layout](../../business/concepts/layout.md).
The fixture is [`front-end/e2e/fixtures/test-floorplan.png`](../../../front-end/e2e/fixtures/test-floorplan.png), an 800x600 floor plan, calibrated as 30 m across so it is a hall that holds the tables with their aisles.
A spec gets its market from `seedLayout()` ([E2E seeds](e2e-seeds.md)): a draft with Upper Hall and Lower Hall and their sections, and a location with no name; asked, it uploads the fixture for Upper Hall and starts its layout, calibrated or not, with tables and no-table zones placed on a calibrated one.

[`LayoutPage`](../../../front-end/e2e/pages/LayoutPage.ts) is their page object: `onScreen()` gives where a point of the hall, in millimetres, is on the screen at any pan and zoom, `clickAt()`, `doubleClickAt()`, `shiftClickAt()`, `hoverAt()` and `drag()` press, rest and drag between such points, `tabToTheMap()` puts the focus on the map from the toolbar by Tab, as a person does, past the fields of an open options strip, and `saved()` wraps a change and waits for the write it starts, since a change waits 600 ms before it is sent and "Saved" still stands from the save before.
Its `drawLine()` drags with `page.mouse` between two points given in the image's pixels, placed on the SVG's box as the SVG draws its image (whole and centred), so the calibration is a real gesture; the line, the scale and the image are read back from the page and the stored layout, never from a store.

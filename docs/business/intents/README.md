# Intents

Part of the [knowledge graph](../../README.md), business layer.
Every file here but this one is a node of kind `intent`, named in kebab-case.

An intent node states an enduring outcome the product commits to, why it matters, and links down to the rules and flows that deliver it.
`describes` is forbidden; `verified` is required.

## Nodes

One line per node, sorted by file name.
